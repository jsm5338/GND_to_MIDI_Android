# GND → MIDI 변환기 (Android Studio)

- 입력: GOGONRB_ODYSSEYSOFT_HEADER / TRACK 컨테이너 GND 파일
- 단일 파일 변환 및 폴더 내 `.gnd` 파일 일괄 변환
- 일괄 변환 결과는 선택한 폴더에 같은 이름의 `.mid` 파일로 저장
- 변환은 앱 내부 백그라운드 작업 스레드에서 실행되어 화면 회전 시 Activity가 다시 만들어져도 작업이 이어짐
- 오프라인 처리, Android Storage Access Framework 사용

## 실행
1. Android Studio에서 프로젝트 폴더를 엽니다.
2. Gradle Sync 후 실행합니다.
3. 단일 파일은 `GND 파일 선택` → `선택 파일 MIDI 변환` → `변환 파일 저장`.
4. 여러 파일은 `폴더 선택 · 일괄 변환`을 누르고 대상 폴더를 선택합니다. 변환된 MIDI는 선택 폴더에 저장됩니다.

## 주의
대용량 파일은 UI 스레드가 아닌 백그라운드에서 순차 처리합니다. 현재 GND 파서는 파일 데이터를 메모리에 읽어 처리하므로, 파일 하나가 기기의 사용 가능한 메모리보다 큰 경우 변환에 실패할 수 있습니다. 폴더 내 바로 아래 단계의 `.gnd` 파일을 처리하며 하위 폴더는 재귀 탐색하지 않습니다.
